# Builder D — finite-core reconstruction (F) and extension to 9 points

Status: see "Results" (filled from the runs). Code: `src/extend_kfield.py` (K_q arithmetic, rigorous
real-root signs), `src/extend_recon.py` (E2 reconstruction), `src/extend_core.py` (extension),
drivers `src/extend_run_recon.py`, `src/extend_run.py`, cross-check `src/extend_crosscheck_e1.py`.
Tests: `tests/test_extend_recon.py`, `tests/test_extend.py`.

## 0. Setting and notation

P is a 9-point crescent configuration: general position (GP), 8 squared distances δ1..δ8, δk occurring
exactly k times. Low pairs are the 3 pairs carrying δ1 or δ2; the other 33 pairs are high, with
values in H = {δ3..δ8} (|H| = 6). A *core* S ⊂ P is a 6-subset whose 15 pairs are all high.
r = |D(S)|, m = 6 − r = number of high values absent from S. F patterns have r ∈ {5,6}, so m ∈ {0,1}.
(The code is written for general n: H has n−3 values, n−6 outside points, m = n−3−r ∈ {0,1};
n = 7, 8 are used only for the known-answer tests.)

Frame: p1 = (0,0), p2 = (1,0), p3 = (0,1) (affine coordinates w.r.t. p2−p1, p3−p1, which are
independent by GP), metric G = [[D12, (D12+D13−D23)/2], [·, D13]], ‖v‖²_G = vᵀGv. Any GP realization
of S is, after relabelling to the F representative and scaling so that z_a = 1, of this form, with G
positive definite (PD) at the corresponding real root.

## 1. Reconstruction of the F cores (primary route: Engine 2 Gröbner, independent of Wang's W)

For a pattern (labels 1..r) let I be generated by the 3×3 minors of L (L_ij = D_1i + D_1j − D_ij),
after exact substitution of the linear relations Az = 0 (Lemma 2.3 rows) and z_a = 1 (a = first free
label). J = I + ⟨tP − 1⟩, P = product of all factors that are nonzero at a GP realization
(z_l, z_l − z_t, the 20 triangle factors 4D_ijD_ik − (D_ij+D_ik−D_jk)², the 15 four-point det(D)).
GB over Q (flint `buchberger_naive`, degrevlex; helpers imported read-only from `src/algebra.py`).

**Claim 1.** Every GP realization of the pattern gives a point of V(J) (normalized tuple + t = 1/P).
*Proof.* Rank L ≤ 2 (L = 2·Gram of p_i − p_1 in ℝ²), linear relations hold (Lemma 2.3, notes
§3/§4 of wang_method.md), and every factor in P is nonzero (positivity, distinct labels,
noncollinear, non-concyclic). ∎

**Claim 2 (finding all points exactly).** If J is zero-dimensional, let A = Q[z,t]/J (basis = standard
monomials of the GB), M_x the multiplication matrices (exact normal forms over Q). For λ = Σ α_k z_k,
the eigenvalues of M_λ are the λ-values of the points of V(J). We factor f = charpoly(M_λ) over Q and
for each irreducible factor q work in K = Q[u]/(q):
 - every evaluation functional ev_p (p ∈ V(J), λ(p) = u) lies in N = ker(M_λᵀ − uI) over K; N is
   invariant under every M_xᵀ (the M commute);
 - if dim N = 1, N = ⟨ev_p⟩ and z_x(p) = (v·M_x e)/(v·e) (v·e = ev_p(1) ≠ 0);
 - if dim N = d > 1 we restrict M_xᵀ to N (invariance checked exactly) and accept only if
   (R_x − τ_x I)^d = 0 with τ_x = tr R_x / d for every x (then only one point has λ = u, z_x = τ_x);
   otherwise the next α is tried.
 Global certificate: the rank of the Hermite trace form [Tr(M_{b_i b_j})] equals the number of
 distinct complex points of V(J); we require Σ deg q = that rank (so λ separates the points and
 nothing is missed). In the run every factor had dim N = 1 and every pattern passed the rank check.
 Then z_j = g_j(u) ∈ K_q for all labels (dependent labels via the linear substitution).

**Claim 3 (Wang §6.1, reimplemented in `reconstruct_core`).** For a factor q: discard if some z_j = 0
or z_j = z_k in K_q, or det G = 0; keep the real roots (exact Sturm count + arb isolation, isolating
balls verified disjoint) where D12 > 0 and det G > 0 (signs decided by interval evaluation refined
until the ball excludes 0; a nonzero element of K_q cannot vanish at a root of irreducible q); solve
2G·p = rhs for p4..p6; verify all 15 distances exactly; verify GP (2×2 orientation dets ≠ 0 and the
4×4 dets with rows (1, pᵀ, pᵀGp) ≠ 0 — under a PD embedding the latter is a nonzero multiple of the
Euclidean incircle det). These checks are also sufficient for a real GP realization at each PD root.

## 2. Extension lemmas (re-derived)

**Lemma T (trilateration).** Let a,b,c ∈ K² be non-collinear and α,β,γ ∈ K. A point x ∈ ℝ²
(under a PD embedding) with ‖x−a‖² = α, ‖x−b‖² = β, ‖x−c‖² = γ satisfies the two linear equations
2(b−a)ᵀGx = ‖b‖²−‖a‖²+α−β, 2(c−a)ᵀGx = ‖c‖²−‖a‖²+α−γ (subtract the first equation from the others).
The coefficient matrix is [2(b−a)ᵀ; 2(c−a)ᵀ]·G, a product of two invertible matrices, so x is the
unique solution and lies in K². Conversely the solution satisfies all three equations iff it satisfies
the first. With both differences 0 (α = β = γ unknown) the solution is the circumcentre of abc, also
in K². *Implementation:* x = x0 + u·w1 + v·w2 with u = α−β, v = α−γ (x0 = circumcentre), and
‖x−a‖² − α = Q0 + B1u + Q1u² + B2v + B12uv + Q2v² − α, a polynomial identity in (u,v); only triples
where this is exactly 0 are returned, then x is formed. (Unit test: planted points are recovered.) ∎

**Lemma H (high-linked points).** Call x ∈ P∖S high-linked if ≤ 1 of its 6 pairs to S is low.
(a) At least 2 of the 3 outside points are high-linked. *Proof:* two non-high-linked points would
contribute ≥ 2 + 2 = 4 distinct low pairs (pairs to S are distinct for distinct outside points), but
only 3 low pairs exist. (General n: ≥ n−7 of the n−6 outside points.)
(b) If m = 0, a high-linked x is a trilateration point of the triangle (1,2,3) or (4,5,6) of S with
values in D(S)³. *Proof:* x has ≥ 5 high pairs to S and every high value lies in D(S) (D(S) = H);
the ≤ 1 low partner lies in at most one of the two disjoint triangles, so the other triangle has all
three distances in D(S); apply Lemma T (S is GP, so the triangle is non-collinear).
(c) If m = 1 (H = D(S) ∪ {d0}, d0 ∉ D(S)), a high-linked x is a trilateration point of some triangle
of S with values in D(S)³, or the circumcentre of some triangle of S. *Proof:* x has ≥ 5 high
partners in S; each high pair carries a value in D(S) or d0. If ≥ 3 carry D(S)-values, apply
Lemma T to three of those partners; otherwise ≥ 3 carry d0, so x is equidistant from 3 distinct
(non-collinear) points of S: their circumcentre. All 20 triangles are used. ∎

**Lemma L (last point).** Let Q = P∖{w}, |Q| = 8. Then w is the circumcentre of a triangle of Q, or a
trilateration point of a triangle of Q with values in D(Q)³; moreover in the second case one may
restrict to any family 𝒯 of triangles of Q such that every 5-subset of Q contains a member of 𝒯.
*Proof:* if a value δk absent from D(Q) has k ≥ 3, all its k ≥ 3 pairs contain w, so w is
equidistant from ≥ 3 points of Q, which are non-collinear: circumcentre. Otherwise every value absent
from D(Q) is δ1 or δ2, which occupy ≤ 3 pairs in total, so ≥ 8 − 3 = 5 of w's pairs to Q carry
values in D(Q); these ≥ 5 partners contain a triangle of 𝒯; Lemma T. (General n: |Q| = n−1,
(n−4)-subsets.) 𝒯 is computed greedily and verified exhaustively in code: |𝒯(8,5)| = 9 triangles (|𝒯(7,4)| = 14, |𝒯(6,3)| = 20 for the tests). ∎

**Corollary (one search per factor).** Every point of a 9-point P containing S lies in K² (the image of
K_q under the real PD embedding σ giving S). All candidate constructions are field operations and all
decisions (equality of points, of squared distances, multiplicities, collinearity, concyclicity) are
zero tests in K_q, which σ preserves. Hence running the search once in the abstract field K_q finds
σ⁻¹(P) for every PD embedding σ, and any K_q-configuration passing the final tests is a real crescent
configuration under every PD embedding of K_q (PD makes distinct points have positive distances).

**Lemma C (capacity tests, necessary).** If Q = S ∪ X (X = selected high-linked outside points)
extends to P with S a core and X high-linked, then μ(d) := (final multiplicity of d) is an injective
map D(Q) → {1..8} with m_Q(d) ≤ μ(d), μ ≥ 3 on D(S), and each x ∈ X has ≥ 5 partners p ∈ S with
μ(‖x−p‖²) ≥ 3. Implementation (exactly equivalent to existence of such μ):
- m = 0: D(S) occupies all six high slots {3..8}, so D(Q)∖D(S) ⊆ {δ1,δ2}: test core counts fit
  {3..8}, non-core counts fit {1,2} (Lemma 5.2: sorted counts a_i ≤ b_{t−s+i}), and each x has ≥ 5
  partners in S with D(S)-values.
- m = 1: for each k ∈ {3..8} (multiplicity of the missing high value d0): core counts fit
  {3..8}∖{k}; and either d0 ∉ D(Q) (non-core counts fit {1,2}; ≥ 5 D(S)-partners), or d0 is some
  observed non-core value with m_Q(d0) ≤ k (other non-core counts fit {1,2}; ≥ 5 partners with values
  in D(S) ∪ {d0}); the same k, d0 for all x ∈ X.
Equivalence with brute force over all injective μ is tested on 1,500 random instances (both verdicts
occur for each (r, |X|)) in `tests/test_extend.py::test_capacity_bruteforce`. The test is applied to
every 7-set S ∪ {x} and to every 8-set S ∪ {x,y}; GP is checked incrementally at each addition.

**Procedure.** For each realizable (pattern, q): candidates for high-linked points (Lemma H), minus S,
deduplicated; keep x if S ∪ {x} is GP and passes Lemma C; for every unordered pair {x,y} of kept
candidates keep Q = S ∪ {x,y} if GP and Lemma C; then the last-point candidates of Q (Lemma L: 56
circumcentres + trilateration over 𝒯 with D(Q)³), minus Q; final test on P = Q ∪ {w}: class sizes
exactly {1,…,8} (8 distinct values) and GP. Anything passing is recorded (with a flag whether D(S)
values all occur ≥ 3 times) and must be re-checked with `src/checker.py`.

Completeness: if P is a 9-point crescent with a core equivalent to an F pattern, relabel and
normalise; by Claims 1–3 the core is a realized factor at a PD root; by Lemma H two high-linked
points x,y are among the candidates; S∪{x}, S∪{y}, S∪{x,y} are GP and pass Lemma C (with μ = true
multiplicities); by Lemma L the ninth point is among the last-point candidates of S∪{x,y}; P passes
the final test. So "0 found" over all realized factors ⇒ no 9-point crescent has an F-core.

### 3.3 Soundness / known-answer tests (`tests/test_extend*.py`, 7 passed)
- `test_extend_recon.py`: 581 exact GP 6-point sets (Palásti subsets, triangular/square lattice,
  two triangles; Q(√3) coordinates, data/algebra_realizable.json) whose pattern is in F. For each,
  the actual normalized tuple is found exactly (q(λ_actual) = 0 and z_l(λ_actual) = actual z_l in
  Q(√3) for all labels), on exactly one factor, which is REALIZED, at a PD root. 581/581.
- `test_palasti_n8` (design): n = 8 analogue (low = δ1,δ2 = 3 pairs, high = δ3..δ7, 2 outside
  points, ≥ 1 high-linked). Palásti has exactly 2 all-high 6-subsets {0,1,2,3,6,7}, {0,1,3,5,6,7}
  (r = 5 = n−3, m = 0); their patterns are POSDIM (in U), so they cannot test reconstruction,
  but they are fed as exact cores (frame coords in Q) to the same Extender code with n = 8.
  Each run outputs exactly one 8-point crescent and it is Palásti (outside points matched by exact
  distance vectors to S); path: high-linked (one point has 2 low pairs to S, the other 1), 7-point
  capacity, last-point lemma with covering 𝒯(7,4). Also passes in `full` mode.
- `test_lattice_n7`: all 8 lattice n = 7 classes; only one has an all-high 6-subset with r ∈ {3,4};
  it is recovered by the last-point lemma (weak test, documented).
- `test_capacity_bruteforce`: capacity() ≡ brute force over all injective μ (1,500 random
  instances, n = 9, r ∈ {5,6}, 1 or 2 selected points, both verdicts in every bucket).
- `test_fits_bruteforce`, `test_covering` (exhaustive verification), `test_trilateration_planted`.
- **Gap in testing:** no known configuration exercises the m = 1 (|D(S)| = n−4) high-linked path
  end-to-end (would need an 8-point crescent with a 4-value all-high 6-subset; none known; a
  radius-4 lattice search for n = 8 was not run because of the CPU cap). That path is covered by the
  proof of Lemma H(c), the planted trilateration/circumcentre test, the capacity brute-force test,
  and by the `full` run (which uses all 20 triangles + circumcentres for every core and agrees).

### 3.5 Bugs / remarks on src/algebra.py (not edited)
- `engine2` uses `buchberger_naive` limits whose third component bounds coefficient bits; 28 F
  patterns stop in < 2 s with "GB(sat) limit" at (10⁴,10⁵,10⁵) — not a time problem. With
  (10⁵,10⁶,10⁶) 22 finish; 6 do not. Not a soundness bug (reported UNRESOLVED, never excluded).
- `_quotient_info` only returns per-variable minimal polynomials, not a joint parametrisation, so it
  cannot by itself give the z-tuples; the joint eigenvector computation here replaces it.
- `reconstruct_F`/`f_univariate`: no bug found; reused read-only for the 6 fallback patterns and the
  cross-check (with my own `reconstruct_core`, which mirrors its checks and adds explicit statuses).
